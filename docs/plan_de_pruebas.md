## 5) Pruebas mínimas por lenguaje
Selecciona tu lenguaje y cumple mínimo lo siguiente:

- **Python:**
  - ejecución de `main.py`,
  - prueba con entrada válida,
  - prueba con entrada inválida.
- **C:**
  - compilación exitosa,
  - ejecución básica,
  - validación de error simple.
- **Bash:**
  - permisos de ejecución,
  - ejecución sin parámetros,
  - manejo de parámetro inválido.
- **ARM64 Assembly (solo proyecto muy pequeño):**
  - ensamblado/enlazado básico,
  - ejecución con salida esperada,
  - validación de caso límite simple.

## 6) Criterios para considerar la práctica terminada
- Documentación principal completa.
- Caso de uso coherente con el alcance.
- Pruebas mínimas registradas.
- Prototipo mínimo funcional (si se implementa).
