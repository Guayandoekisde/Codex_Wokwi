# Checklist breve de validación

## 1) Checklist de pruebas mínimas
- [ ] Ejecuté al menos 3 casos de prueba.
- [ ] Registré entrada y resultado esperado.
- [ ] Registré resultado obtenido.
- [ ] Incluí al menos 1 prueba de error.

## 2) Checklist de documentación
- [ ] Completé `docs/propuesta.md`.
- [ ] Completé `docs/caso_de_uso.md`.
- [ ] Revisé `docs/estructura_repositorio.md`.
- [ ] Completé `docs/plan_de_pruebas.md`.

## 3) Checklist de ejecución
- [ ] Verifiqué que `scripts/run.sh` funcione en local.
- [ ] Ajusté `scripts/run.sh` al lenguaje elegido.
- [ ] Confirmé que existe `src/main.<ext>` correcto.

## 4) Checklist de entrega final
- [ ] El repositorio mantiene estructura ordenada.
- [ ] El proyecto se mantiene pequeño y viable.
- [ ] No usé frameworks, nube, APIs externas ni dependencias complejas.
- [ ] Entregué documentación antes del prototipo.
